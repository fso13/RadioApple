# Roadmap и бэклог

Список задач и фич для RadioMac. Приоритеты:

- **P0** — качество эфира и дистрибуция: без этого приложение теряет в надёжности или
  не может нормально распространяться.
- **P1** — ежедневный сценарий: заметно улучшает повседневное использование.
- **P2** — расширение и технический долг: полезно, но не блокирует релиз.

✅ — реализовано, тесты 22/22.

> ✅ RM-25: код и тесты готовы; OAuth/scrobble нужно проверить с ключами Last.fm.
>
> 🚧 RM-27, этап 2: AVPlayer для HLS, выбор движка и нативный Biquad EQ для BASS; ICY для AVPlayer и удаление BASS — следующие этапы.
>
> ⚠️ RM-18 и RM-19 требуют Apple Developer team и provisioning profile:
> без него `com.apple.security.application-groups` (App Groups) и iCloud не работают.
> Ad-hoc сборка падает с «requires a provisioning profile».

Каждый ID — кандидат в карточку GitHub Project
[RadioMac #11](https://github.com/users/fso13/projects/11). В колонке «Результат» —
критерий готовности.

## P0 — сначала

| ID | Задача | Результат |
| --- | --- | --- |
| RM-01 ✅ | **Рабочий эквалайзер на Apple Silicon** | 10 полос и пресеты работают на macOS 27/arm64 без ошибки BASS_FX 41; настройки сохраняются. Замена BASS_FX на `AVAudioUnitEQ` или совместимую сборку. |
| RM-02 | **Поддержка HLS** | Потоки `.m3u8` (например, SOUNDPARK DEEP) играют через AVPlayer/AVAudioEngine; метаданные и Now Playing работают. |
| RM-03 | **AAC без x86_64** | AAC-потоки (Radio Maximum) играют на Apple Silicon без Rosetta: universal `libbass_aac` или CoreAudio-путь. |
| RM-04 | **Автопереподключение потока** | При обрыве — статус «Переподключение…», backoff 1/2/5/10 с, ограничение попыток и ручной retry. Поток восстанавливается без перезапуска станции. |
| RM-05 | **Подпись Developer ID и нотарификация** | Релизные DMG/PKG подписаны, нотарифицированы и stapled; `spctl --assess` проходит на чистом Mac; в заметках релиза нет `xattr`-инструкции. |
| RM-06 | **Убрать Flutter-наследие из main** | Flutter-версия перенесена в ветку/тег `flutter-legacy`; в `main` нет `macos/Podfile` и `Runner.xcodeproj`; CI/CodeQL больше не спотыкаются о старый проект. |

## P1 — ежедневный сценарий

| ID | Задача | Результат |
| --- | --- | --- |
| RM-07 | **Таймер сна** | 15/30/60/90 минут, плавное затухание за 5 секунд, индикатор в окне и меню-баре, отмена. |
| RM-08 | **Глобальные горячие клавиши** | Настраиваемые play/pause и следующая станция при скрытом окне; проверка конфликтов с системными шорткатами. |
| RM-09 | **App Intents, Shortcuts и URL scheme** | Команды «Играть станцию», «Пауза», «Открыть окно»; URL `radiomac://play/<id>`; интеграция с приложением «Команды». |
| RM-10 | **История треков** | Последние 100 треков: станция, время, исполнитель; поиск, копирование, очистка; хранение локально. |
| RM-11 | **Поиск по Radio Browser** | Поиск тысяч станций по названию, жанру и стране, превью потока, добавление в библиотеку и защита от дублей. |
| RM-12 | **Импорт и экспорт станций** | OPML, M3U и JSON; drag-and-drop, выбор «добавить/заменить», сохранение избранного. |
| RM-13 | **Настройки на станцию** | Смещение громкости, свой EQ-пресет и автозапуск для конкретной станции; сохраняется в библиотеке. |
| RM-14 | **Автообновление (Sparkle 2)** | Appcast, EdDSA-подпись, проверка обновлений в приложении и в CI; переход с 1.0.1 на 1.0.2 без ручного DMG. |
| RM-15 | **Мини-плеер в меню-баре** | Поповер с обложкой, названием, play/pause, громкостью и быстрым выбором станции — без открытия основного окна. |
| RM-16 | **Локализация и доступность** | String Catalogs для ru/en; VoiceOver-метки, порядок фокуса, контраст, Reduce Motion; проверка основных экранов. |
| RM-17 | **UI-тесты и снапшоты** | XCUITest для главного сценария и настроек; снапшот-тесты светлой/тёмной темы; запуск в CI. |

## Порядок работы

1. **RM-05** (подпись) и **RM-04** (стабильность) — быстрые победы, которые сразу
   повышают доверие к релизам.
2. **RM-01…RM-03** или **RM-27** — закрыть главные ограничения звука.
3. **RM-06** — упростить репозиторий и CI.
4. Далее P1 по одному-два пункта на релиз; P2 — по запросу.
