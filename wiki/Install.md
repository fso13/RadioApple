# Установка

## Требования

| | |
| --- | --- |
| macOS | 14 (Sonoma) или новее |
| Процессор | Apple Silicon или Intel (universal) |
| Место | около 10 МБ |
| Интернет | нужен для потоков, метаданных и логотипов |

## Вариант 1: Homebrew

```bash
brew tap fso13/tap
brew trust fso13/tap   # Homebrew 7+
brew install --cask radiomac
```

Cask ставит последний стабильный релиз и обновляется вместе с ним. Если
Gatekeeper блокирует ad-hoc сборку, установите с `--no-quarantine`:

```bash
brew install --cask --no-quarantine radiomac
```

Удаление: `brew uninstall --cask radiomac`.

## Вариант 2: DMG (рекомендуется)

1. Скачайте `RadioMac-<версия>.dmg` со страницы
   [последнего релиза](https://github.com/fso13/RadioApple/releases/latest).
2. Откройте образ двойным кликом.
3. Перетащите **RadioMac** на иконку **Applications** (или в папку «Программы»).
4. Извлеките образ и запустите приложение из «Программ» или Spotlight.

![Окно установки](https://raw.githubusercontent.com/fso13/RadioApple/main/site/assets/screenshots/installer-window.png)

После первого запуска в меню-баре появится иконка радио. Окно открывается левым кликом
по ней; правый клик — меню с действиями. В Dock приложения нет — это нормально, так задумано.

## Вариант 3: PKG

1. Скачайте `RadioMac-<версия>.pkg`.
2. Двойной клик → «Продолжить» → «Установить».
3. Запустите приложение.

PKG ставит приложение в `/Applications` и подходит для управляемой установки.

## Gatekeeper и карантин

Релиз подписывается **ad-hoc**, если в CI не настроены сертификаты Developer ID.
На другом Mac macOS может отказаться открывать приложение («Не удаётся открыть,
так как разработчик не может быть проверен»).

Разрешить запуск можно так:

```bash
xattr -dr com.apple.quarantine /Applications/RadioMac.app
```

Затем откройте приложение снова. Если сборка подписана Developer ID и нотарифицирована,
этот шаг не нужен. Наличие подписи можно проверить:

```bash
codesign --verify --strict --verbose=2 /Applications/RadioMac.app
spctl --assess --type execute --verbose /Applications/RadioMac.app
```

## Проверка файлов

В релизе лежат `SHA256SUMS.txt` и SBOM `RadioMac-<версия>.spdx.json`.
Скачайте файлы в одну папку и выполните:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Все строки должны быть `OK`. SBOM описывает состав сборки и используется в CVE-проверках
(подробнее — в разделе [Безопасность](Security)).

## Обновление

1. Завершите приложение: меню в меню-баре → «Завершить», или Настройки → «Завершить RadioMac».
2. Замените `RadioMac.app` новой версией (DMG/PKG).
3. Запустите снова.

Bundle id не меняется (`com.fso13.radioMac`), поэтому станции, избранное, громкость,
тема и пресет эквалайзера сохраняются. Настройки и данные лежат в контейнере песочницы:

```
~/Library/Containers/com.fso13.radioMac/Data/Library/Preferences/
```

## Удаление

1. Завершите приложение.
2. Перетащите `RadioMac.app` из «Программ» в Корзину.

Чтобы удалить также все данные (станции, избранное, настройки):

```bash
rm -rf ~/Library/Containers/com.fso13.radioMac
```

> **Внимание:** эта команда необратима. Свои станции и избранное будут потеряны.

## Первый запуск

- Иконка появляется в меню-баре; в Dock и Cmd+Tab приложения нет.
- Левый клик — показать/скрыть окно, правый — меню (играть/пауза, стоп, настройки, выход).
- Если включить «Продолжать последнюю станцию», эфир начнётся сразу после запуска.
- Автозапуск включается в [Настройках](Settings).
