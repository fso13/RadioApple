# Безопасность

## Поддерживаемые версии

| Версия | Поддержка |
| --- | --- |
| 1.x | да |
| < 1.0 | нет |

## Как сообщить об уязвимости

Не открывайте публичный issue. Используйте
[GitHub Security Advisory](https://github.com/fso13/RadioApple/security/advisories/new)
или напишите мейнтейнеру. Укажите версию, macOS, шаги воспроизведения и оценку влияния.

## Модель угроз

RadioMac — локальное приложение без аккаунтов и серверной части. Оно открывает
аудиопотоки по HTTPS/HTTP, загружает метаданные, обложки и логотипы. Пользовательские
данные не покидают Mac.

- **Песочница** включена (`com.apple.security.app-sandbox`).
- Сетевое право — только `com.apple.security.network.client`.
- Запись — только в контейнер `~/Library/Containers/com.fso13.radioMac/`.
- Нет телеметрии, аналитики и сторонних SDK.
- Нет сторонних исполняемых аудиоплагинов: только системный AVFoundation.

## Зависимости

- Пакетных менеджеров в рантайме нет: только системные фреймворки macOS.
- Внешних аудиобиблиотек нет; аудио идёт через системный AVPlayer.
- Python-инструменты сборки закреплены: `scripts/requirements-installer.txt`,
  `scripts/requirements-dev.txt`.

## Автоматические проверки

| Проверка | Где | Что делает |
| --- | --- | --- |
| CodeQL (`swift`) | `codeql.yml` | семантический анализ кода |
| SwiftLint | `lint.yml` | статический анализ стиля и ошибок |
| actionlint | `lint.yml` | проверка workflow |
| ShellCheck | `lint.yml` | проверка shell-скриптов |
| OSV-Scanner | `security.yml` | уязвимости в зависимостях (OSV.dev) |
| SBOM + Grype | `security.yml` | SBOM приложения и скан CVE (порог critical) |
| Dependency Review | `security.yml` | блокировка PR с уязвимыми зависимостями |
| Dependabot | `dependabot.yml` | обновления actions и pip-инструментов |
| Аудио | AVFoundation | системный AVPlayer без сторонних бинарников |

Результаты сканов загружаются в **Security → Code scanning**.

SBOM (`RadioMac-<версия>.spdx.json`) публикуется в релизе. Он описывает приложение
и его компоненты; аудио идёт через системные фреймворки Apple, внешних C-библиотек нет.

## Целостность релиза

- DMG и PKG подписываются; при наличии секретов — Developer ID и нотарификация.
- В релизе лежат `SHA256SUMS.txt` и SBOM.
- Проверка контрольных сумм:

  ```bash
  shasum -a 256 -c SHA256SUMS.txt
  ```

- Проверка подписи:

  ```bash
  codesign --verify --strict --verbose=2 /Applications/RadioMac.app
  spctl --assess --type execute --verbose /Applications/RadioMac.app
  ```

Если сборка ad-hoc, macOS может потребовать снять карантин:

```bash
xattr -dr com.apple.quarantine /Applications/RadioMac.app
```

## Секреты в CI

`release.yml` принимает сертификаты и пароли только из GitHub Secrets. Сертификат
импортируется во временную keychain, файл `.p12` удаляется после импорта. Секреты
не печатаются и не попадают в артефакты. Без секретов релиз собирается ad-hoc.

## Автообновление

Публичный Ed25519-ключ Sparkle лежит в Info.plist, приватный — только в GitHub
Secrets. Appcast и DMG подписываются в release workflow; приложение проверяет
подпись перед установкой. Канал обновлений — latest release, без Pages.

## Виджет

Виджет и приложение используют `/Users/Shared/RadioMac/nowplaying.json` через
sandbox temporary-exception. В файле только название станции/трека, id и флаг
воспроизведения; он доступен локальным пользователям Mac. App Group не
используется, поэтому подпись остаётся ad-hoc. Это осознанный обход требования
provisioning profile для локальной сборки; для App Store нужен Developer team.

## Last.fm

Скробблинг выключен по умолчанию. API-ключи приложения приходят из GitHub Secrets
при сборке и не лежат в git; сессия Last.fm хранится в Keychain. Запросы уходят
только на `ws.audioscrobbler.com` после явного включения и авторизации. Пользователь
может отключить аккаунт или удалить ключи в настройках.

## ICY side-channel

Для прогрессивных AVPlayer-потоков открывается второй запрос к тому же URL с
`Icy-MetaData: 1`. Он нужен только для `StreamTitle`, аудио не сохраняется и
никуда не отправляется. Для HLS side-channel не используется.

## Краш-репорты

Приложение не отправляет краш-репорты. Вместо этого есть **opt-in локальный журнал**:
пользователь сам включает его в настройках, записи лежат в контейнере и содержат
только версию приложения, статусы плеера, названия станций/домены и ошибки.
URL обрезаются до домена, данные не покидают Mac. Журнал можно скопировать,
очистить или показать в Finder.

## Известные ограничения

- Эквалайзер — нативный Biquad DSP в AVPlayer audio tap.
- BASS/BASS_FX/BASS_AAC удалены; аудио идёт через системный AVPlayer.
- Сторонние потоки и API могут быть недоступны или geo-заблокированы — это
  не уязвимость приложения.

## История треков

История последних 100 треков хранится локально в `UserDefaults` и не отправляется
на серверы. Очистка удаляет её без возможности восстановления. Глобальные
горячие клавиши не требуют Accessibility-разрешения.
