# Горячие клавиши

## В окне

| Клавиши | Действие |
| --- | --- |
| `Esc` | убрать фокус из поиска; если поле не активно — скрыть окно |
| `Space` | пауза / продолжить |
| `↑` `↓` | двигать выделение по списку |
| `Return` | играть выделенную станцию |
| `1`…`9` | сразу включить станцию с этим номером в текущей выборке |
| `⌘F` | фокус в поиск |
| `⌘N` | новая станция |

## Как это работает

- Шорткаты активны, когда окно RadioMac в фокусе.
- `⌘F` и `⌘N` работают всегда, в том числе когда курсор в текстовом поле.
- `Space`, стрелки, `Return` и цифры **не перехватываются**, пока вы печатаете в поиске
  или в форме станции, — можно спокойно вводить название.
- `Esc` в текстовом поле снимает фокус, а не закрывает окно. Повторный `Esc` скрывает окно.
- Номера `1`–`9` считаются по **видимому** списку: если включён жанр или поиск, цифры
  относятся к отфильтрованным станциям.
- Скрытие окна не останавливает воспроизведение.

## Меню-бар

| Действие | Результат |
| --- | --- |
| Левый клик по иконке | показать / скрыть окно |
| Правый клик по иконке | меню действий |
| Пункт «Играть» / «Пауза» | управление эфиром без открытия окна |
| Пункт «Стоп» | остановить поток |
| Пункт «Настройки» | открыть настройки |
| Пункт «Завершить» | полностью закрыть приложение |

## Глобальные горячие клавиши

По умолчанию:

| Действие | Комбинация |
| --- | --- |
| Играть / пауза | `⌥⌘P` |
| Следующая станция | `⌥⌘→` |

Работают при скрытом окне. Изменить можно в **Настройках → Глобальные горячие
клавиши**; при конфликте с системой показывается ошибка.

## Now Playing

Во время эфира RadioMac публикует трек в Control Center. Системные кнопки
play/pause работают и при скрытом окне. Отдельные глобальные горячие клавиши
приложение не регистрирует.

## Где изменить поведение

- Продолжение последней станции и автозапуск — в [Настройках](Settings).
- Поиск, избранное и жанры — на главном экране, см. [Возможности](Features).
