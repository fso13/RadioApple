# Метаданные и обложки

RadioMac показывает не только название станции, но и текущий трек, исполнителя и обложку.
Данные приходят из открытых источников; аккаунт не нужен.

## Откуда берётся трек

При каждом включении станции и далее каждые **20 секунд**, пока играет эфир, плеер
опрашивает источники по порядку:

1. **Radio Paradise** — `api.radioparadise.com`, если поток этой станции.
2. **SomaFM** — `somafm.com/songs/<канал>.json`.
3. **Icecast** — `status-json.xsl` на хосте потока.
4. **ICY-теги** — `StreamTitle` из самого потока.

Если источник вернул пустые данные, используется следующий. Для станций без метаданных
в нижней панели остаётся название станции, а подпись сообщает, что данных о треке нет.

## Разбор ICY

Из `StreamTitle='Artist - Title'` выделяются исполнитель и трек; разделитель — дефис.
Служебные строки и мусор отбрасываются. Если в теге пришёл URL картинки, он используется
как обложка.

## Обложки

- Сначала проверяется обложка из метаданных трека (Radio Paradise, SomaFM, ICY).
- Затем — поиск в **iTunes Search API** по строке «исполнитель + трек».
- Результат кэшируется в памяти, чтобы не повторять запросы.
- Если ничего не найдено, показывается логотип станции; если нет и его — заглушка.

Логотипы станций ищутся отдельно: Radio Browser → сайт из ICY → favicon домена.
Подробнее — в разделе [Свои станции](Stations).

## Now Playing и Control Center

Во время эфира приложение публикует в систему:

- название трека и исполнителя;
- обложку;
- команды play/pause.

Поэтому трек виден в Control Center и на кнопках медиа-клавиатуры. При остановке
эфира публикация снимается.

## Если данные неверные

- Проверьте, что станция сама отдаёт метаданные: у многих потоков ICY-тегов просто нет.
- Название и исполнитель берутся из ответа станции, ручной коррекции в приложении нет.
- Для SomaFM и Radio Paradise нужен доступ к их API; при блокировке сети останутся
  ICY/Icecast или ничего.
- Обложка может не найтись, если трек редкий или название сильно сокращено.

## Приватность

Запросы идут напрямую к публичным API и к хостам станций, с собственным User-Agent.
Приложение не отправляет телеметрию и не требует входа. Список доменов, к которым
обращается плеер, виден в исходниках:

- `RadioMac/Services/NowPlayingLookup.swift`
- `RadioMac/Services/LogoResolver.swift`
- `RadioMac/Services/NativeAudioEngine.swift`

## Где это в коде

| Файл | Ответственность |
| --- | --- |
| `RadioMac/Services/NowPlayingLookup.swift` | Radio Paradise, SomaFM, Icecast, ICY, iTunes |
| `RadioMac/Models/NowPlaying.swift` | модель трека и парсер `StreamTitle` |
| `RadioMac/Services/RadioPlayerService.swift` | опрос раз в 20 секунд, состояние плеера |
| `RadioMac/Services/NowPlayingCenter.swift` | MPNowPlayingInfoCenter и команды |
| `RadioMac/Services/LogoResolver.swift` | логотипы станций |
