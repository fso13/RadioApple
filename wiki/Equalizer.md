# Эквалайзер

## Как открыть

- Кнопка эквалайзера в нижней панели плеера.
- Или Настройки → Звук → «Настроить».

Открывается отдельное окно с переключателем, пресетами и десятью полосами.

![Эквалайзер](https://raw.githubusercontent.com/fso13/RadioApple/main/site/assets/screenshots/equalizer.jpg)

## Полосы

10 полос: **32, 64, 125, 250, 500 Гц, 1, 2, 4, 8, 16 кГц**. Диапазон усиления —
**от −12 до +12 дБ**. Полоса рисуется тонкой линией: вверх — усиление, вниз — ослабление.
Значение показывается над ползунком.

## Пресеты

| Пресет | Характер |
| --- | --- |
| Плоский | все полосы 0 дБ |
| Свой | ваша кривая; появляется, когда двигаете полосы |
| Бас | подъём низких, лёгкое ослабление верха |
| Высокие | подъём верхних частот |
| Голос | середина для речи и подкастов |
| Рок | подъём низов и верха |
| Поп | середина и верх |
| Джаз | мягкие низы и верх |
| Электро | низы и верх для электронной музыки |
| Классика | умеренный подъём краёв |
| Речь | акцент на середине, срез низов |

Пресет применяется сразу. Движение полос переключает пресет на «Свой».
Кнопка «Сбросить» возвращает «Плоский».

## Сохранение

Эквалайзер общий для всех станций. Состояние (`eq_enabled`, `eq_preset`, `eq_gains`,
`eq_custom_gains`) хранится в `UserDefaults` и переживает перезапуск. Переключение
эквалайзера не перезапускает поток — звук меняется на лету.

## Известное ограничение

На некоторых системах (в частности, macOS 27 / Apple Silicon) поставляемый
`libbass_fx.dylib` загружается, но BASS отвергает его с **ошибкой 41**. В этом случае:

- окно эквалайзера показывает предупреждение;
- переключатель и полосы недоступны (настройки при этом сохраняются);
- поток играет без коррекции.

### Как включить коррекцию

Нужна совместимая сборка BASS_FX под вашу архитектуру:

1. Замените `ThirdParty/BASS/libbass_fx.dylib`.
2. Пересоберите приложение ([Сборка](Build)).
3. Убедитесь, что библиотека подписана вместе с приложением (скрипт сборки это делает).
4. Обновите `ThirdParty/BASS/SHA256SUMS` через `scripts/verify_third_party.sh --update`.

Если BASS_FX заработает, интерфейс включится автоматически: проверка доступности
происходит при старте.

## Где это в коде

| Файл | Ответственность |
| --- | --- |
| `RadioMac/Models/EqualizerPreset.swift` | полосы, частоты, пресеты, клампинг |
| `RadioMac/Services/EqualizerService.swift` | состояние, применение, сохранение |

| `RadioMac/UI/EqualizerView.swift` | интерфейс и фейдеры |
